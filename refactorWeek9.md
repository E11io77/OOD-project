Week 9 refactor:

The focus was on RecyclingGuidanceService. Firstly, getGuidance() method was classified as a static (unlike other service classes already present in the project). That means it cannot be injected, which is against our checklist from week 6. Thanks to the refactor getGuidance() returns raw data only. Secondly, it returned a formatted String instead of data, which meant the UI logic was in the application layer. It should not have decided over the look of the output. It therefore violated the Single Responsibility Principle too, as RecyclingGuidanceService was also managing the formatting. The tests were also adjusted as it was always coming as failure – the test classes were not public and the entire project was moved from OneDrive to local disk as it was problematic to run tests.
